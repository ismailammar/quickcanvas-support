How to resize an image on Mac

Resizing can mean two things: scaling the whole picture smaller or bigger, or changing the canvas to add or trim space. Both are quick on a Mac.

In Preview

Choose Tools > Adjust Size, enter the new width or height, and keep Scale proportionally ticked.

In Quick Canvas

  1. Choose Image > Resize Canvas (Shift Command R), or click the resize button in the Image group.
  2. Enter the new width and height in pixels (up to 8000 by 8000).
  3. Tick Stretch the picture to the new size to scale the image. Leave it off to add or remove space instead, keeping the picture anchored top left.
  4. To make the file itself smaller, choose Save As and set Quality to Smaller file with JPG or HEIC.

Common questions

How do I reduce a photo's file size on Mac?

Save it as JPG or HEIC with the Smaller file quality option in Quick Canvas, or use Export in Preview with a lower quality slider.

Will resizing make my picture blurry?

Making it smaller keeps it sharp. Making it much bigger than the original always softens detail.
