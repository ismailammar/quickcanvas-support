How to save an image as PDF on Mac

You do not need an online converter to turn a picture into a PDF on a Mac. Both methods below work offline, keep your file private and add no watermark.

Method 1: with Preview (built in)

  1. Open the picture in Preview.
  2. Choose File > Export as PDF.
  3. Pick a name and location, then click Save.

Method 2: with Quick Canvas (edit first, then save as PDF)

  1. Open the picture with File > Open, or paste it with Command V.
  2. Make any edits: crop, add text, arrows or highlights.
  3. Choose File > Save As (Shift Command S).
  4. Set Format to PDF.
  5. Set Quality: High quality keeps every detail; Smaller file makes photo PDFs much smaller for email.
  6. Click Save. The PDF is one page the exact size of your picture.
PDFs saved by Quick Canvas have the computer's system version and creation timestamps removed, so the file carries nothing but your picture.

Common questions

How do I convert a JPG to PDF on Mac for free?

Open it in Preview and choose File > Export as PDF. It is built into every Mac and works offline.

Can I make a PDF smaller on Mac?

In Quick Canvas, choose Save As, set Format to PDF and Quality to Smaller file. This mainly shrinks photos; simple drawings are already small.

Does saving as PDF reduce image quality?

Not with High quality selected. The picture is stored at its full resolution.
