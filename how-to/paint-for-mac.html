Is there Paint for Mac?

Short answer: no. Microsoft Paint only runs on Windows, and Macs do not come with a paint program. You have two options: make do with Preview, which is built into every Mac, or install a simple paint app such as Quick Canvas.

What the Mac has built in: Preview

Preview opens pictures and has a Markup toolbar (View > Show Markup Toolbar) for sketching, shapes, text and cropping. It is fine for marking up a screenshot, but it is not a paint program: there is no fill bucket, no brushes, no free-form selection to move pixels around, no gridlines and no blank canvas to draw on from scratch.

Common questions

Can I install Microsoft Paint on a Mac?

Not natively. Microsoft Paint is a Windows app. Running it would mean installing Windows in a virtual machine, which is costly and slow for simple picture edits.

What is the Mac equivalent of Paint?

macOS has no direct equivalent. Preview handles basic markup. For a true paint program with brushes, fill, shapes and free-form selection, use a simple paint app such as Quick Canvas.
