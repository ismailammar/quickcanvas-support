How to crop a screenshot on Mac

The quickest crop is to capture only the part you need. When you have already taken a full screenshot, crop it afterwards in Preview or Quick Canvas.

Capture just the area you need

ShortcutWhat it does
Shift Command 4Drag to capture an area, saved to the desktop
Shift Command Control 4Drag to capture an area, copied to the clipboard
Shift Command 5Screenshot toolbar with more options

Crop an existing screenshot in Preview

  1. Open it in Preview and drag a box around the part to keep.
  2. Choose Tools > Crop (Command K).

Crop and mark up in Quick Canvas

  1. Copy a screenshot to the clipboard with Shift Command Control 4, then press Command V in Quick Canvas. Or open the file with File > Open.
  2. Pick the rectangle select tool and drag around the part to keep.
  3. Press Command K to crop to the selection.
  4. Add arrows, boxes, a see-through marker highlight or text.
  5. Save as PNG for sharp text, or JPG or PDF to send.

Common questions

What is the shortcut to crop on Mac?

In Preview and Quick Canvas, select an area and press Command K.

How do I add an arrow to a screenshot on Mac?

In Quick Canvas, pick one of the four arrow shapes and drag it onto the screenshot. Hold Shift for straight lines in Preview or Quick Canvas.

Which format is best for screenshots?

PNG keeps text perfectly sharp. Use JPG or PDF when the file needs to be small or printed.
